# Windows Command Prompt Commands

This file contains common Windows commands used in the command prompt.

## Basic Commands

### 1. `dir`
Shows the list of files and folders in the current directory.

```cmd
dir
```

### 2. `cd`
Changes the current directory.

```cmd
cd Documents
```

### 3. `mkdir`
Creates a new folder.

```cmd
mkdir MyFolder
```

### 4. `rmdir`
Deletes an empty folder.

```cmd
rmdir MyFolder
```

### 5. `copy`
Copies a file from one location to another.

```cmd
copy file1.txt file2.txt
```

### 6. `move`
Moves a file or folder.

```cmd
move file1.txt C:\Users\YourName\Documents
```

### 7. `del`
Deletes a file.

```cmd
del file1.txt
```

### 8. `cls`
Clears the screen.

```cmd
cls
```

### 9. `echo`
Displays text or creates a file with content.

```cmd
echo Hello World
```

### 10. `ipconfig`
Shows network configuration details.

```cmd
ipconfig
```

## Useful Tips
- Use `cd ..` to go to the parent folder.
- Use `dir /s` to search files recursively.
- Use `help` to see available commands.
